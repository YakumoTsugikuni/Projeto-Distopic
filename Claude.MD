
# Frontend Development Guidelines

## Stack obrigatória
- HTML5 semântico
- CSS3 puro
- JavaScript Vanilla (ES6+)
- Não utilizar React, Vue, Angular ou outros frameworks.
- Não utilizar Tailwind ou Bootstrap.

## Design
- Criar interfaces modernas, elegantes e profissionais.
- Evitar aparência genérica de interfaces geradas por IA.
- Utilizar hierarquia visual bem definida.
- Escolher tipografias adequadas à identidade do projeto.
- Trabalhar com espaçamentos consistentes.
- Criar paletas de cores harmoniosas.
- Utilizar animações sutis e intencionais.
- Priorizar consistência visual entre páginas.

## Responsividade
- Desenvolver primeiro pensando em uma boa experiência mobile.
- Garantir compatibilidade com desktop, tablet e celular.
- Utilizar Flexbox e CSS Grid quando apropriado.
- Evitar elementos que causem overflow horizontal.

## Qualidade
- HTML semântico e acessível.
- CSS organizado e reutilizável.
- JavaScript modular e legível.
- Estados de hover, focus, active e disabled.
- Verificar contraste e navegação por teclado.
- Não utilizar elementos meramente decorativos sem propósito.

## Processo de desenvolvimento
1. Analisar os requisitos.
2. Definir a direção visual.
3. Planejar a estrutura da interface.
4. Implementar HTML, CSS e JavaScript.
5. Verificar responsividade.
6. Revisar visualmente e corrigir inconsistências.
